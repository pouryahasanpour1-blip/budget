📩 ثبت خودکار پیامک بانک

گوشی اجازه نمی‌ده اپ خودش پیامک‌ها رو بخونه، ولی با یه اتوماسیون (Shortcuts روی آیفون، MacroDroid روی اندروید) هر پیامک بانک خودکار برای اپ فرستاده می‌شه. اپ مبلغ، تاریخ و نوع تراکنش رو پر می‌کنه و تو فقط ذخیره رو می‌زنی.
اول آدرس رو کپی کن
مراحل ساخت اتوماسیون
۱
برو به Automationاپ Shortcuts رو باز کن، پایین صفحه تب Automation رو بزن و بعد ＋ یا New Automation.
۲
گزینه‌ی Messageاز لیست Message رو انتخاب کن.
۳
فرستنده یا متن پیامکجلوی Sender شماره یا مخاطب بانکت رو بزن. یا جلوی Message Contains کلمه‌ای مثل برداشت بنویس.
۴
بدون پرسیدن اجرا بشهگزینه‌ی Run Immediately رو انتخاب کن و بعد Next، و بعدش New Blank Automation.
۵
اکشن URLاکشن URL رو اضافه کن و آدرسی که کپی کردی رو بچسبون. بعد آخرِ آدرس (بعد از sms=) متغیر Shortcut Input رو بذار، روش بزن و Content رو انتخاب کن.
۶
اکشن Open URLsاکشن Open URLs رو اضافه کن و Done رو بزن.
مراحل با MacroDroid
۱
نصب MacroDroidاپ رایگان MacroDroid رو از گوگل‌پلی نصب کن و اجازه‌ی خوندن پیامک رو بهش بده.
۲
ماکروی جدیدAdd Macro رو بزن.
۳
تریگر پیامکتوی Triggers گزینه‌ی SMS Received رو انتخاب کن و شماره یا اسم فرستنده‌ی بانکت رو بده.
۴
اکشن باز کردن آدرستوی Actions گزینه‌ی Open Website / HTTP GET (بخش Connectivity) و بعد Open Website رو انتخاب کن.
۵
آدرس و متن پیامکآدرسی که کپی کردی رو بچسبون. بعد آخرش (بعد از sms=) با دکمه‌ی ... متغیر SMS Message رو اضافه کن.
۶
ذخیرهماکرو رو ذخیره کن و اسمش رو بذار «بودجه». مرورگر پیش‌فرض رو همون مرورگری انتخاب کن که اپ رو باهاش نصب کردی (مثلاً Chrome).
با Tasker هم می‌شه: پروفایل Event › Phone › Received Text و تسک Browse URL با %SMSRB آخر آدرس.
اگه کار نکرد
• اگه مبلغ پیدا نشد، صفحه‌ی ثبت سریع با متن پیامک باز می‌شه تا اصلاحش کنی.
• اگه به‌جای اپ، Safari باز شد، اطلاعات Safari از اپ صفحه‌ی اصلی جداست.
• برای هر بانک یه اتوماسیون جدا بساز.

🎙 میانبر Siri

بعد از ساختن این میانبر، کافیه به Siri بگی «ثبت خرج» و بعد بگی مثلاً «ناهار ۱۵۰ هزار». مبلغ و دسته خودکار پر می‌شن.
اول آدرس رو کپی کن
مراحل ساخت در اپ Shortcuts
۱
اپ Shortcuts رو باز کنپایین صفحه برو تب Shortcuts و بالا دکمه‌ی ＋ رو بزن.
۲
اکشن Ask for Inputتوی کادر جستجو بنویس Ask for Input و انتخابش کن. جای Prompt بنویس: چی خرج کردی؟
۳
اکشن URLجستجو کن URL و اضافه‌ش کن. آدرسی که کپی کردی رو اونجا بچسبون.
۴
متن Siri رو تهِ آدرس بذارمکان‌نما رو ببر آخرِ آدرس (بعد از add=)، از نوار بالای کیبورد متغیر Provided Input رو بزن.
۵
اکشن Open URLsجستجو کن Open URLs و اضافه‌ش کن. خودش به URL مرحله‌ی قبل وصل می‌شه.
۶
اسم بذاربالای صفحه روی اسم میانبر بزن و بنویس ثبت خرج، بعد Done.
مثال‌هایی که می‌تونی بگی
«قهوه ۸۵ هزار» · «تاکسی ۱۲۰ هزار #کار» · «خرید ۲ میلیون»
اگه کار نکرد
• اگه قفل رمز روشنه، اول رمز رو می‌زنی و بعد تراکنش ثبت می‌شه.
• اگه به‌جای اپ، Safari باز شد، اطلاعات Safari از اپ صفحه‌ی اصلی جداست. اپ رو از همون Safari دوباره به Home Screen اضافه کن یا آدرس رو از داخل اپ کپی کن.
• میانبر رو می‌تونی به‌عنوان ویجت یا Action Button هم بذاری.

📥 بکاپ CANdo

فایل بکاپ CANdo را انتخاب کن یا متن بکاپ را اینجا بچسبان. اطلاعات به داده‌های فعلی اضافه می‌شود و چیزی پاک نمی‌شود. اگر دوباره وارد کنی، موارد تکراری ساخته نمی‌شود.
